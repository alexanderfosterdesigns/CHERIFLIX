# CHERIFLIX UI screenshots

Source-faithful 1920×1080 PNG references extracted from the current Flutter UI implementation.

- `01_splash.png` — loading/splash state
- `02_profiles.png` — profile chooser
- `03_home.png` — home hero and first content rail
- `04_search.png` — TV keyboard and search results
- `05_my_list.png` — continue watching and saved titles
- `06_details.png` — title detail view
- `07_settings.png` — profile and playback settings
- `00_contact_sheet.png` — overview of all screens

The screenshots use the repository’s actual CHERIFLIX branding, color constants, font files, labels, sizing targets, and 16:9 TV canvas. Media artwork is represented by the app’s dark fallback surfaces because the repository does not contain TMDb poster/backdrop artwork or a configured TMDb API key.
