## Changes shown

- Portrait/square-feeling media cards changed to cinematic 16:9 cards.
- Card spacing increased to give focused TV controls more breathing room.
- Rails display fewer, larger cards at once for better viewing distance.
- TMDb backdrop artwork is now preferred over portrait posters for these cards.
- Light buttons use near-black text/icons for accessible contrast.

These are source-faithful design references using the same 1920×1080 viewport and content. Placeholder surfaces are shown because the repository does not include redistributable TMDb poster/backdrop files; live builds populate those surfaces from TMDb.
